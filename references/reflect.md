# reflect：把「这次产出好不好」记下来，下次别再犯

> 复盘记录只给「你」和「下一次调用」看，一个字都不进候选输出。

## 它解决什么问题

`feedback`（点选/改写）记的是「你最后怎么反应的」，`trace`（决策记录）记的是「模型当时怎么判的」。
两件事各自都记了，但中间缺一环：**这一次产出的后果，没有回流成下一次的约束**。

具体断在三个地方：

1. **判错了不知道错在哪**。你改写了候选，`feedback` 只记「改成了什么」，不记「模型当时判了什么阶段/意图/danger」。
   「阶段判错导致全错」和「判对了只是措辞不对」，在反馈里长得一样，下次还是错。
2. **漏了事实不知道漏了什么**。候选「没接住具体事实」时，`verify` 的 notes 会提示一句，但这句话不落盘，
   下次换个人调（或换个模型）又漏一遍。
3. **trace 是死胡同**。它能记录决策链，但产出后没人读它、也不和反馈关联——「能看见决策，看不见决策的后果」。

`reflect` 补上这一环：把**决策 → 结果 → 下一次约束**串起来。它不是新判断，是把已经存在、但散落丢弃的信息收拢成可复用的事实。

## 输入：一段复盘记录

```json
{
  "slot": "couple_early",
  "stage": "couple_early",
  "intent": "vent",
  "danger": 3,
  "strategies": ["care", "repair"],
  "picked": "repair",
  "edited": "是我没接住你那句",
  "missed_fact": "她昨天加班到十点",
  "trap": "把「加班」当成了普通累，给了一堆方案"
}
```

| 字段 | 含义 | 必填 |
| --- | --- | --- |
| `slot` | 哪个档案 | 是 |
| `stage` / `intent` / `danger` | 模型当时判的 | 否（有就记，判得越全下次越省事） |
| `strategies` | 模型给的策略 | 否 |
| `picked` | 你最后选了哪条策略 | 否 |
| `edited` | 你改成什么样（比 picked 信息量大） | 否 |
| `missed_fact` | 模型漏掉的、本该用上的具体事实 | 否 |
| `trap` | 这一条踩的坑，一句话说清「错在哪」 | 否 |

## 输出：它把「坑」翻译成「下次的约束」

`reflect` 不做情感判断，只做三件机械的事：

1. **把 `missed_fact` 落成档案事实**。模型漏掉的通常是「她身上已经存在、但这次没召回」的事实——
   要么没建档，要么没打 tag。`reflect` 会提示这条事实该补进档案、该配什么 tag。
2. **把 `trap` 落成一条「易错点」**。同一类坑踩第二次时，`brief` 会在摘要里带一句提醒，
   不让模型再在同一个地方栽跟头。
3. **把 `edited` 落成风格样本**。你的改法比「选了哪条」更能说明「你本来会怎么说」，
   和 `feedback` 的 edited 一样进样本库，但这里顺带记下「为什么这么改」（trap），信息更全。

## 运行

```bash
python scripts/profile_tool.py reflect --json '{"slot":"couple_early","trap":"把加班当普通累","missed_fact":"她昨天加班到十点"}'
```

或存文件：

```bash
python scripts/profile_tool.py reflect --file reflect.json
```

## 三条红线（和 balance 同一套纪律）

1. **不给她定罪**：`trap` 只写「模型哪里判断错了」，不写「她这人怎么这样」。复盘的对象是产出，不是她。
2. **不自动改候选逻辑**：`reflect` 落下的「易错点」只进 `brief` 的提醒，**不改 danger、不改阶段闸门、不改策略白名单**。
   它让模型「下次注意」，不替模型「重新定规则」。
3. **结果不进候选**：`reflect` 的结论是给下一次调用看的元信息，永远不写成候选正文的一部分。

## 为什么「记坑」比「记对」有用

人最容易记的是「这次又踩了什么坑」，而不是「这次哪句说得对」。因为「对」的场景千差万别、
很难复用，而「错」通常就那么几类：把疲惫当冷淡、把沉默当拒绝、把她的抱怨当成要方案。
把这几类坑记下来、下次在 `brief` 里带一句「她说过累的时候别说这些」，比记一百条「这次选得好」更能提下限。
