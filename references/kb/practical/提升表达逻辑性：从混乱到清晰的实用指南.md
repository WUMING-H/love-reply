# 提升表达逻辑性：从混乱到清晰的实用指南

## 导航

1. 先给结论，再给依据
2. 用固定框架，别想到哪说到哪
3. 做减法，只留核心
4. 预判对方会问什么

## 定位

用于「要一个解释」、要把事情说清楚、或对方要一个说法时。核心一条：**先给结论，再给依据，别让对方猜你想说什么**。但注意——这是「说事」的场景，不是「谈感情」的场景。她在生气时，要的不是逻辑清晰的解释，是先接住情绪；先读 [吵架技巧](万能吵架技巧：理性冲突处理指南.md)。

## 一、先给结论

混乱的表达是「想到啥说啥」，对方抓不住重点。清晰的做法是反过来：

- 先说结论（「项目能按时交付」），再说依据（「因为零件到了、团队已开工」）。
- 先抓核心，再补细节。核心是「你想让对方记住的那一句」，细节是支撑。

## 二、用固定框架

不用每次现想结构，套三个现成框架之一：

1. **总分总**：结论 → 两三个依据（每个配一个例子）→ 重申结论。
2. **时间线**：过去（问题/情况）→ 现在（进展）→ 未来（计划）。适合讲过程、说进度。
3. **PREP**：观点 → 理由 → 例子 → 重申观点。适合说服、提建议。

框架的作用是「不跑偏」，不是「显得专业」。用最简单的那个。

## 三、做减法

表达冗长的病根是「舍不得删」。三步：

1. **抓核心**：先问自己「我最想让对方知道的是哪一句」。
2. **去冗余**：删掉和核心无关的细节（「我昨天喝了三杯咖啡」和结论无关，删）。
3. **排优先级**：剩下的按重要程度排，先讲最重要的依据。

说漏细节没关系，补一句「刚才漏了个点」，比一股脑全倒出来清晰。

## 四、预判对方会问什么

表达前想一下「对方可能问什么」，提前把答案放进去，逻辑才闭环：

- 提建议时，对方会问「成本多少」「多久见效」——主动说，别等问。
- 提前堵漏洞，比对方一问就慌、现补强。

一句话：**逻辑表达是「替对方省理解成本」，不是「展示自己条理清晰」**。
