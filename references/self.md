# 自我档案 · 我是谁、我要什么、我不能做什么

给她建档，解决的是「她是谁」。这一份解决的是「我是谁」。

两件事缺一不可。只懂她不懂自己，会得到一份"聪明但不适合你"的建议——话术挑不出错，但方向不是你想要的。

---

## 1 为什么需要这一层

没有自我档案时，模型默认优化一个东西：**这条消息本身的效果**。它会让对方舒服、让对话继续、让气氛变好。

但你要的可能不是这些。同样是「她三天没回」：

| 你的目标 | 该给的候选 |
|---|---|
| 想挽回 | 一条低压力的、给台阶的、留门的话 |
| 想看清她还要不要 | 一条能问出真实态度、又不带审问感的话 |
| 想体面收尾 | 一条把话说完整、不留钩子的话 |

三条完全不同。**默认优化会给出第一条**，因为它"效果最好"。这就是为什么必须把目标显式写下来。

自我档案还解决第二个问题：**你以为自己会说、实际说出来的话，和你的短板之间往往有固定落差**。有人一急就连发三条，有人一被质疑就开始列时间线，有人道歉永远只认态度不认事。这些模式重复出现，写下来就能被拦住。

## 2 六类条目

```bash
python scripts/profile_tool.py self add --kind <类型> --text "..." [--forbid 词...] [--evidence "..."]
```

| 类型 | `kind` | 存什么 | 例子 |
|---|---|---|---|
| 性格 | `trait` | 稳定的行为倾向，带证据 | 被质疑时先解释再共情，顺序总是反的 |
| 短板 | `flaw` | 你反复犯的错，会毁掉好候选 | 她一沉默就连发三条追问 |
| 底线 | `limit` | 你不做的事、不接受的条件 | 不接受异地，不为了恋爱换城市 |
| 能兑现 | `capacity` | 时间、钱、精力的真实边界 | 工作日只能八点后，周末常加班 |
| 看重 | `value` | 你在关系里真正在意的东西 | 看重被明确回应，受不了长期模糊 |
| 说话 | `voice` | 自述的语言习惯（统计卡之外的补充） | 打字快，容易一次发三段 |

**最有用的是 `limit` 和 `flaw`。** 它们直接删掉候选，不是提供背景。

- `limit` 进了守门，`我下个月搬过去` 这条候选根本不会出现在你面前
- `flaw` 进了守门，你不会再收到"在吗"这种你自己的坏习惯

`trait` 和 `value` 影响的是**判断倾向**，不拦截文本。`capacity` 影响承诺——这是它最实际的作用，见第 5 节。

---

## 3 底线必须配触发词

只写一句"我不接受异地"是没用的。模型读到了，但它不知道该在什么情况下回避什么说法。

```bash
# 只写这句，守门查不出来
self add --kind limit --text "不接受异地"

# 配了触发词，才能真正拦住
self add --kind limit --text "不接受异地，不为了恋爱换城市" \
  --forbid 搬过去 去你那边 换工作 辞职
```

`--forbid` 是**字面匹配**，写的是「不该出现在候选里的说法」，不是主题。所以：

- 写「搬过去」「去你那边」，不要写「异地」——后者太宽，会误伤"你在深圳吗"这种正常问句
- 写「在吗」「你怎么了」「怎么不回」，这是 `flaw` 的典型触发词
- 一个底线配 2–5 个词就够，配多了容易误伤

没配触发词时脚本会警告，因为那时候守门是空的。

## 4 关系目标：方向、跨度、硬度

```bash
python scripts/profile_tool.py goal add --slot couple_early \
  --kind advance --horizon season --hard \
  --text "三个月内把关系明确下来，不要一直悬着" \
  --forbid 再看看 顺其自然
```

**五个方向**（`--kind`）

| 方向 | 含义 | 典型候选 |
|---|---|---|
| `advance` | 推进：从当前状态往前走一步 | 明确关系、见家长、同居 |
| `hold` | 稳住：先别动，把现状维持住 | 刚吵完，先不推进 |
| `repair` | 修复：把断掉的部分接回来 | 冷战后的第一句 |
| `exit` | 收尾：把话说完整，不留钩子 | 想清楚了，要结束 |
| `understand` | 看清：先搞清楚她怎么想，再决定 | 信号不明，不急着行动 |

**三个跨度**（`--horizon`）

| 跨度 | 含义 | 会不会进摘要 |
|---|---|---|
| `now` | 这次对话 | 会，且排最前 |
| `season` | 这个阶段（几周到几个月） | 会 |
| `long` | 长期，几乎不变 | 会，但优先级低于前两个 |

**硬与软**（`--hard`）

- 硬目标：**不许被任何话术牺牲**。守门会按它的 `forbid` 拦截候选，命中就重写。
- 软目标：进入打分，影响三条候选的排序，但不会硬删。

两者区别很实际。硬目标"不接受异地"——任何涉及搬家的候选直接作废。软目标"想三个月内明确"——不删候选，但会优先推那一条。

**同时进行中的目标不要超过四条。** 超过之后模型会在它们之间摇摆，每条都照顾一点，每条都不深。脚本会在第四条时提醒。

## 5 能兑现的范围：承诺的真正闸门

`capacity` 是这份档案里最被低估的一类。

判断层有一条硬规则「不许替用户承诺」，但那条规则一直缺数据——模型不知道你几点下班、周末有没有空、预算多少，只能给一个模糊的、谁都能说的方案。

写进去之后：

```
能兑现 工作日只能八点后，周末常加班
```

候选就从 `下午三点我去接你` 变成 `八点后我去接你`。

**写法要点**：写约束的另一面，不要写形容词。

```
❌ 我比较忙
✅ 工作日八点后才有空，周末不一定
❌ 经济压力大
✅ 月内可支配的约会预算 800 左右
```

前者模型没法用，后者能直接算进候选。

## 6 目标裁决：三步，顺序不能换

生成候选时，目标按这个顺序参与：

**第一步：硬目标过滤。**
候选里出现任何硬目标的 `forbid` 词 → 直接删掉，不参与排序。

**第二步：阶段优先。**
目标要求的手段如果被当前阶段禁止，**阶段赢，目标延后**。

```
目标：三个月内明确关系（想 advance）
阶段：repairing（禁 advance）
→ 不是放弃目标，是这次不说。正确输出：先把上次那件事说清楚
```

唯一例外：目标是 `exit` 时，阶段闸门放宽——你不需要维持关系，只需要把话说完整。

**第三步：软目标进打分。**
`goal_fit` 的定义从「这条消息的效果」变成「这条消息对你目标的贡献」。这是排序权重里最大的那一项（0.7）。

三步都过了，才是候选择优。

## 7 自我认知的三种污染

写自己的时候，比写别人的时候更容易失真。三种典型：

| 形态 | 长什么样 | 后果 | 对策 |
|---|---|---|---|
| 美化 | 「我只是不太会表达，其实我很在乎」 | 模型按"深情但不善言辞"设计候选，实际是回避沟通 | 只写行为，不写动机。改成「她一追问我就说'算了没事'」 |
| 贬损 | 「我就是个废物，她看不上我正常」 | 候选全部偏低姿态，反而降低吸引力 | 同样只写行为：「我一紧张就道歉，即使不是我的错」 |
| 标签化 | 「我是回避型依恋」 | 标签一贴就不再看具体情境，行为变了也照旧 | 标签不入库，只存具体行为 |

一条通用判据：**能用摄像头拍到的是行为，拍不到的是解释。** 只收前者。

```
❌ 我很敏感
✅ 她隔两小时没回，我会反复看手机
❌ 我有点讨好型
✅ 她说不方便，我会立刻改自己的安排
```

左边这些模型无法执行，右边这些能直接变成拦截规则。

## 8 说话习惯与风格卡的关系

两者会重叠，处理原则：**统计优先，自述补充。**

| 来源 | 内容 | 可信度 |
|---|---|---|
| 风格卡（`data/style/*.json`） | 从真实语料算出来的 p50 字数、句号率、ai 词频 | 高，可验证 |
| `voice`（自我档案） | 你对自己说话方式的描述 | 低，容易失准 |

冲突时以风格卡为准。`voice` 的用处是**填风格卡算不出来的东西**：

- 场景差异："跟她说话会短一半，跟朋友会贫"
- 意图："我经常用『行』表示同意，不是敷衍"
- 习惯动作："生气时反而变短，不是冷暴力"

这些统计抓不到，但会影响解读。

## 9 什么时候录

不用一次填完。三个自然时机：

**一、第一次使用时，录这三条就够启动。**

```bash
python scripts/profile_tool.py self init
python scripts/profile_tool.py self add --kind limit --text "..." --forbid ...
python scripts/profile_tool.py self add --kind flaw --text "..." --forbid ...
python scripts/profile_tool.py goal add --slot <槽位> --kind <方向> --text "..."
```

**二、每次候选选错的时候。** 你看到三条都不满意，通常说明缺一条自我认知或一条目标。这时候补，比凭空想有效。

**三、阶段变化时。** 关系状态变了，目标往往也要变。旧的 `advance` 目标留在 `repairing` 阶段会让模型一直想推进，记得 `goal done` 或 `goal drop`。

完整的自我访谈脚本在 `prompts/self-interview.md`，十二问，分三轮。**不要一次问完**，先解决当下的事。
