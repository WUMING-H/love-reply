# 投入对账（balance）

> 只给「你」看，一个字都不进候选输出。

## 它解决什么问题

判断一段关系该继续还是该收，最常见的错误是用「感觉」——「她到底爱不爱我」「她是不是不在乎我」。
这些感觉一旦变成结论，就会反过来污染你接下来写的每一句话：带着「你是不是在耍我」的预设去回复，
对方能感觉到，然后更彻底地关上。

`balance` 不做这些。它只把两边**客观行为**摆在一起，让「单向」自己显出来。

## 输入：一段行为记录

四类，每类「我」和「她」各一个字符串列表：

| 字段 | 含义 | 例子 |
|---|---|---|
| `initiate` 主动发起 | 谁先找话题、谁先约 | 「每天找话题」「也会主动问」 |
| `give` 实际付出 | 谁做了什么具体的事 | 「熬夜做 PPT」「分享工资条」 |
| `emotion` 情绪投入 | 谁分享、谁回应、谁在意 | 「随时接她情绪」「吐槽闺蜜」 |
| `avoid` 回避逃避 | 谁遇事就躲、装没看见 | 「遇课表就转移」「装死」 |

JSON 格式：

```json
{
  "mine": {
    "initiate": ["每天找话题", "主动约"],
    "give": ["熬夜做PPT", "送花", "每天送回家"],
    "emotion": ["随时接她情绪"],
    "avoid": []
  },
  "hers": {
    "initiate": [],
    "give": [],
    "emotion": [],
    "avoid": ["遇课表就转移", "遇护手霜装死"]
  }
}
```

运行：

```bash
python scripts/profile_tool.py balance --json '{"mine":{...},"hers":{...}}'
```

## 输出：三档 + 事实明细

- **有来有往**：投入大致对等。别挑刺，继续正常流程。
- **你多她少**：你明显投入更多。**先别下「她不在乎」的结论**——可能是阶段使然，也可能她投入的方式和你不一样。
- **几乎单向**：绝大部分投入在你这边，她几乎没实质回应。**这是需要正视的事实。** 该往回收——先把你的力气和期待收回来，看她会不会主动补一点。

每一档都附 `detail`，把四类各自的「你几条 / 她几条 / 净差」列出来，让你看到是**哪一类**在失衡，
而不是笼统一句「单向」。

## 三条红线（必须遵守）

1. **不给她定罪**：输出里不出现「她不成熟」「她自私」「她吸你的能量」这类定性。只摆「谁做了什么」。
2. **不下关系判决**：不出现「这段没戏」「该分手」「该出局」。该不该继续，是**你自己**看完事实后做的决定，工具不替你下。
3. **结果不进候选**：`balance` 的结论是给你自己的一面镜子，**永远不**作为写回复的素材。哪怕结果是「几乎单向」，
   下一句候选该怎么写，仍按 `judge` + `compose` + `guard` 的正常流程走，不掺入「我投入了这么多」的怨气。

## 为什么「只看行为，不下结论」是对的

你真正要判断的不是「她是什么人」，而是「这段关系的投入是不是单向的」。前者是病理化、是猜测、
是把你自己的委屈包装成对她的诊断；后者是可观察、可核对的事实。工具只做后者，把前者的判断权
完整地留给你。
