# v0.16.0

把「事后才想起来」变成「当下就能避开」。这一版的核心是让 `reflect` 落下的易错点在模型写候选的那一刻就可见、且越反复越醒目；同时把最大的单文件脚本按层拆开，为后续迭代铺路。

## 复盘回流升级：易错点分级 + 写候选时可见

上一版 `reflect` 把踩的坑落成易错点，但只在 `brief` 里带一句提醒——模型写候选（`verify`）时根本看不到，等于「事后才想起来，当下已经栽了」。这一版补上：

- **踩坑计数**：同一条 trap 每再踩一次 count 累加。踩 1 次是 `[易错]` 软提醒，踩 ≥2 次升级为 `[反复栽] …写之前先停下确认`，越反复越醒目。
- **verify 也带出易错点**：输出新增 `pitfalls` 字段，和 brief 同一套分级，让模型在「写候选」这个真正出错的时刻就能看到坑，不再只靠事后兜底。
- **红线不变**：pitfalls 仍是提醒元信息，进输出不改 verdict、不改 danger、不改阶段闸门。

## 工程：profile_tool 按层拆分

`profile_tool.py` 从 1938 行单文件拆成包结构，不改任何行为，纯降技术债：

- 拆成五层：`constants`（常量）、`storage`（存储 + 检索）、`render`（摘要渲染）、`guard`（守门 + 信号判断）、`commands`（26 个命令）。
- `import profile_tool` 及所有符号访问路径零破坏；`scripts/profile_tool.py` 保留为薄壳入口，CLI 调用方式照旧，文档与 CI 一行不改。
