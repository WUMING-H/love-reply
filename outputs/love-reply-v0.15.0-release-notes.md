# v0.15.0

把「翻车」变成「下一次不再犯」。这一版补上了反馈链路的最后一环——之前 feedback 记「你最后怎么反应」、trace 记「模型当时怎么判」，但两者都不回流成下一次的约束。现在 `reflect` 把它们串起来，并针对一个具体的人做了两层不越线的优化。

## 复盘回流：reflect 命令

`feedback`（点选/改写）和 `trace`（决策记录）都有，但它们的后果从来没回流成「下一次的约束」——判错了不知道错在哪、漏了事实不知道漏了什么、trace 是死胡同没人读。`reflect` 补上这一环：

- **`profile_tool.py reflect`**：收一段复盘记录（trap 踩的坑 / missed_fact 漏的事实 / edited 你的改法），做三件机械的事——trap 落成档案「易错点」、missed_fact 提示补档（不自动写，事实要你确认来源）、edited 进风格样本并多记一句「为什么这么改」。
- **`brief` 带出「易错」提醒**：落档的 trap 下次出现在摘要里（`[易错] …`），让模型别在同一个地方再栽。它不占「她」的记忆额度，不改 danger、不改阶段闸门，只做「这次注意」。
- **三条红线**：不给她定罪（trap 只写「模型哪里判断错了」）、不自动改候选逻辑、结果不进候选。

## 针对一个人的两层优化

基于一份真实关系反馈（大模型调用 skill 后产出的复盘），只沉淀「可执行的客观信号」，严格守住红线——定性词（不成熟/自私/耗死/出局）一个字都不进 skill。

- **第一层：候选措辞更准**。默认画像新增「已知的客观信号」三节（很少主动发起、遇压力话题转移或沉默、有信任基础），全写成行为事实而非定性；新增「讨回应催回复」软提示，拦住「把回避的人逼走」的追问。
- **第二层：投入对账 `balance`**。新增命令，只给用户看、不写进候选。收「谁主动/谁付出/谁逃避」四类客观行为，输出「有来有往 / 你多她少 / 几乎单向」三档，摆事实不下结论。

## 变更

- `feat(persona+balance)` 候选措辞优化 + 投入对账命令
