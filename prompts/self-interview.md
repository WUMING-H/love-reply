# 自我访谈 · 十二问，分三轮

这份脚本用来把你对自己的了解，变成 Skill 能用的条目。

**不要一次问完十二个。** 一轮一轮来，每轮答完就落库，看到效果再继续。一次抛十二个问题，多数人答到第三个就开始敷衍。

用法：把下面「第一轮」整段发给模型，或自己照着答。答完让它跑 `self add` / `goal add`。

---

## 第一轮：边界（四问）

先问边界，因为边界最容易答，也最快改变输出——它直接删候选。

**1. 有没有什么事，你确定不会为这段关系做？**

> 例：搬去她的城市、辞职、跟家里借钱、婚前同居

落库：`self add --kind limit --text "不接受异地，不为了恋爱换城市" --forbid 搬过去 去你那边`

⚠️ **必须配 `--forbid`**，写「不该出现在候选里的说法」。不配的话守门拦不住，这条就等于没录。

**2. 你的时间、钱、精力，实际边界在哪？**

> 例：工作日只能八点后，周末常加班，一个月能拿出来的约会预算八百左右

落库：`self add --kind capacity --text "工作日八点后才有空，周末不一定"`

这一条最影响候选能不能落地。没它，模型会建议「明天下午三点我去接你」，而你那天在开会。

**3. 你在关系里最不能忍的是什么？**

> 例：长期模糊、被冷处理、被拿去和别人比

落库：`self add --kind value --text "受不了长期模糊，要给明确回应"`

**4. 反过来，什么会让你一下子软下来？**

> 例：她主动说想我、她记得我说过的小事

落库：`self add --kind value --text "她记得我随口说过的事，这一下就没脾气"`

这条会影响候选的落点——同样一句关心，接在「她记得」上还是接在「她道歉」上，效果差很远。

---

## 第二轮：模式（五问）

这一轮问的是**你反复犯的错**。它比第一轮难答，但价值更高——底线是「不做」，模式是「总在做」。

**5. 她一沉默，你会做什么？**

> 例：连发三条、反复看手机、开始写长段解释

落库：`self add --kind flaw --text "她一沉默就连发三条追问" --forbid 在吗 怎么不回 生气了`

**6. 你被质疑的时候，第一反应是什么？**

> 例：先解释，越解释越像辩解；或者直接沉默

落库：`self add --kind trait --text "被质疑时先解释再共情，顺序总是反的" --evidence "上次她说我不上心，我先列了时间线"`

**7. 你生气的时候，说话会变成什么样？**

> 例：变短、变客气、开始用「随便你」

落库：`self add --kind voice --text "生气时反而变短，会用「行」「随便你」"`

这条能防住一类典型误判：模型看到短回复，以为你没事。

**8. 你道歉的时候，通常漏掉哪一半？**

> 例：只说「对不起」不说具体哪件事；或者说清了事但没认情绪

落库：`self add --kind flaw --text "道歉只认态度不认具体那件事"`

**9. 你最容易在什么时刻做出后悔的决定？**

> 例：深夜、喝了酒、连续加班第三天

落库：`self add --kind trait --text "连续加班到第三天会变得很急，容易说重话"`

---

## 第三轮：方向（三问）

前两轮问「怎么做」，这一轮问「要什么」。方向错了，前两轮全白搭。

**10. 这段关系，你现在到底想要什么？**

必须选一个方向，不能答「看情况」：

| 你的真实想法 | `--kind` |
|---|---|
| 想往前走一步，定下来 | `advance` |
| 不想动，先把现状维持住 | `hold` |
| 断掉的部分想接回来 | `repair` |
| 想清楚了，要结束 | `exit` |
| 还没想清楚，先搞清楚她怎么想 | `understand` |

落库：
```bash
goal add --slot couple_early --kind advance --horizon season --hard \
  --text "三个月内把关系明确下来，不要一直悬着" --forbid 再看看 顺其自然
```

**11. 这个目标有时间吗？**

没时间的目标不会产生任何紧迫感，模型也就不会为你争取时机。给一个粗糙的期限就行：「这个月」「过年前」「她生日之前」。

落库：填 `--horizon`（`now` 这次 / `season` 本阶段 / `long` 长期）和 `--due`。

**12. 如果只能保住一样，你保哪样？**

> 例：保自尊，所以不做低姿态的事；保关系，所以可以先低头

这一条决定**冲突时怎么选**。它会成为最后一行建议的依据：三条候选都踩线时，保什么。

落库：`self add --kind value --text "冲突时可以低头，但不做反复道歉轰炸"`

## 落库后怎么检查

```bash
python scripts/profile_tool.py self list
python scripts/profile_tool.py goal list --slot couple_early
python scripts/profile_tool.py brief --slot couple_early --query "随便一句最近在聊的话"
```

`brief` 应该输出成这样：

```
[我]
目标! 三个月内把关系明确下来（本阶段·推进）
底线 不接受异地，不为了恋爱换城市
短板 她一沉默就连发三条追问
能兑现 工作日八点后才有空
[她·couple_early·自2026-03]
任务 把磨合期的分歧说清楚，不攒着
```

看不到 `[我]` 段，说明 `self init` 没跑，或者条目 kind 写错了。

## 三条写法要求

**一、写行为，不写评价。**

```
❌ 我很敏感
✅ 她隔两小时没回，我会反复看手机
❌ 我有点讨好型人格
✅ 她说不方便，我会立刻改自己的安排
```

左边模型没法执行，右边能变成拦截规则。

**二、`limit` 和 `flaw` 必须配 `--forbid`。**

`--forbid` 是字面匹配的词，不是主题。写「搬过去」「去你那边」，不要写「异地」——后者会误伤「你在深圳吗」这种正常问句。

**三、不要一次录十几条。**

先录最疼的三条：一条底线、一条短板、一个目标。用几次，发现哪条候选又偏了，再补。一次录满的档案，往往一半是想象出来的。

---

## 什么时候重录

| 时机 | 动作 |
|---|---|
| 关系阶段变了 | `goal done` 旧的，加新的 |
| 候选连续三次都不满意 | 补一条 `flaw`，通常是它缺了 |
| 发现自己定的底线其实能松 | `forget` 掉，别留着自欺 |
| 半年没用过某条 | `self list` 过一遍，删掉不像自己的 |

自我档案比她的档案更需要复核。人会变，而记录不会自己变。
