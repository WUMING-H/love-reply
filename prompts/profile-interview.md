# 建档访谈 · 十二个问题

用来从零建立恋爱档案。**分三轮问，答完一轮再下一轮**——一次抛十二个问题，多数人答到第三个就走了。

前提：先用 `prompts/standalone.md` 或 `SKILL.md` 解决他当下要回的那条消息，再问「要不要花十分钟建个档案，以后不用重复交代」。

---

## 第一轮：基本盘（四问）

```
1. 怎么称呼她？在一起多久了，或者认识到哪一步了？
2. 她平时做什么？作息大概什么样？
3. 你们一般多久见一次，谁主动多一些？
4. 最近一次让你不舒服的事是什么？
```

这四个问题定了 `stage`、时间密度和当前张力。第 4 问尤其重要——它往往是整个档案里最该被记录的一条。

**录入**：

```bash
python scripts/profile_tool.py init --slot couple_early --alias 她 --stage couple_early --since 2026-03
python scripts/profile_tool.py add --slot couple_early --kind fact \
  --text "她在科技园上班，九点下班是常态" --source "她说的"
```

---

## 第二轮：她的偏好与边界（四问）

```
5. 她明确说过不喜欢什么？（做法、说法、约会方式）
6. 什么事你做了之后，她明显高兴？
7. 她生气的时候是什么样——变冷、变长、还是直接说？
8. 你们吵过最凶的一次是因为什么，后来怎么好的？
```

第 5、6 问产出 `landmine` 和 `soother`，是七类条目里最能改变回复的两个。
第 7 问决定 `danger` 往高还是往低判；第 8 问决定修复策略能不能用。

**录入**：

```bash
python scripts/profile_tool.py add --slot couple_early --kind landmine --text "她说累的时候别讲道理"
python scripts/profile_tool.py add --slot couple_early --kind soother --text "带她吃那家牛肉锅，吃完就好了"
python scripts/profile_tool.py add --slot couple_early --kind read \
  --text "生气时先变冷，两小时后才会说原因" --confidence high \
  --evidence "三次吵架都是这个节奏" --tag 冲突
```

---

## 第三轮：承诺与未解（四问）

```
9.  你答应过她什么还没做？
10. 有什么事你一直没搞懂，但不好意思问？
11. 你觉得自己最常犯的错是什么？
12. 你现在最想推进的是什么？
```

第 9 问进 `promise`，带到期日——它直接防止 AI 建议你许一个做不到的新承诺。
第 10 问进 `unknown`，这是档案里最诚实的一栏，用来对抗"我什么都懂"的错觉。
第 11 问往往对应一条 `landmine`，只不过炸的是你自己。

**录入**：

```bash
python scripts/profile_tool.py add --slot couple_early --kind promise \
  --text "陪她去看那个展" --due 2026-11-15
python scripts/profile_tool.py add --slot couple_early --kind unknown \
  --text "她问展是真想去，还是随口一提"
```

---

## 录入时的三条判断

用户答什么就记什么，但记之前要想清楚它属于哪一类：

| 他的说法 | 该记成 | 理由 |
|---|---|---|
| 「她生日 11 月 27 日」 | `fact` | 可核验 |
| 「她不喜欢被安排」 | `read`，置信中 | 是判断，可能来自一两次误会 |
| 「她就是回避型」 | 拆成具体行为 | 标签不入库，行为变了标签就该变 |
| 「我觉得她最近有点冷淡」 | `read`，置信低 | 只有感觉，没有证据 |
| 「她说累的时候我讲道理她会炸」 | `landmine` | 具体、可执行、能改变候选 |
| 「我可能太粘人了」 | `read`，置信中，tag=自我 | 也很重要，会影响建议尺度 |

**不要替他下结论。** 他说「她好像不太想理我」，你不能记成「她不想理他」——那是两回事，
前者是他的感受，后者是事实断言。

---

## 收尾：给他看一眼

录完不要直接结束，回一段让他能核对的摘要：

```
记了 8 条：
· 事实 3 条：生日 11/27、科技园上班、不吃芒果
· 你的判断 3 条：不喜欢被安排（中）、工作压力大（中）、可能在考虑分手（低）
· 雷区 1 条：她说累时别讲道理
· 承诺 1 条：陪她看展，11/15 前

「可能在考虑分手」我标了低置信，下次只会帮你写一句去问清楚的话，不会围着它出主意。
有要改的直接说。
```

最后一句不是客套——低置信条目是最容易被误用的东西，先说清楚它怎么被使用，用户才敢把真实想法写进去。

---

## 不用建档案的情况

- 只回一条消息、以后不打算常用 → 让他用 `prompts/standalone.md` 就行。
- 关系刚开始（`stranger`）→ 信息太少，建了也是空的，等有几次实质对话再说。
- 他明确说不想记录私人信息 → 尊重，直接跳过。档案是增强，不是前置条件。
