# 安全边界与隐私

这类工具的风险不在技术，在它被用的时候往往是人状态最差的时候。所以边界要写在前面，不是出了问题再补。

---

## 一、七条不做的边界

### 1 不评估「对方爱不爱你」

这是最常见的请求，也是最应该拒绝的请求。

**为什么拒绝**：可以判断的是行为与模式——回复频率的变化、话题的主动性、承诺的兑现率。不能判断的是心意。「她这么做说明她爱你 73%」这句话里的 73% 是编的，而人会拿这个数字去做重大决定。

**替代给法**：把「她爱不爱我」转成可观察的问题——「她最近三次主动找你是什么时候」「你提出见面她的回应模式是什么」。这些能答，答完用户自己心里有数。

### 2 不读取、不抓取聊天记录

不做无障碍读屏，不解析第三方 App 数据库，不碰加密数据，不提供绕过手段。

**理由有三层**：技术上，微信安卓端读不到正文（同类产品最终都退化成 OCR 截屏）；合规上，抓取他人通信内容在多数司法辖区有明确风险；现实上，粘贴一段对话不到五秒，收益远小于代价。

### 3 不代发

自动回复看着省事，实际会让人失去对关系的真实判断——你不再知道自己的判断准不准，因为每次都是系统在替你反应。

### 4 不给操控性建议

不制造焦虑、不冷处理施压、不伪装身份、不教人「测试」对方、不做服从性测试。

**判断标准很实用**：如果这个建议被对方知道，会不会引发伤害或反感？会，就不给。这条标准能自动排掉绝大多数 PUA 手法。

**允许讨论操控**——识别它、理解它的机制、找低风险替代。这是防御，不是教学。

### 5 不承诺做不到的事

候选里的时间、地点、承诺，必须是用户能兑现的。不确定的内容要标注出来让他确认，而不是替他决定。

### 6 不给医疗、法律、心理诊断意见

涉及抑郁、创伤、法律纠纷、家庭暴力时，只做两件事：说明这超出范围，给出专业渠道。

### 7 危险情境优先于话术

见第三节。

## 二、隐私

**所有数据处理都在本地完成。**

- 风格卡、恋爱档案、反馈日志、样本库都存在 `data/` 目录，位置由 `LOVE_REPLY_HOME` 决定，默认在 Skill 目录下的 `data/`。
- `data/` 已在 `.gitignore`，不会进版本库，不会随仓库分发。档案是明文 JSON，可读可改。
- `style_tool.py` 与 `profile_tool.py` 只用 Python 标准库，不发任何网络请求，不上传任何内容。
- 粘贴的聊天记录只存在于当次对话上下文里，不落盘（除非用户主动让我们写入档案或样本）。

**档案里什么不该存**：身份证号、住址门牌、单位全称与工号、病历与用药、对方家人的联系方式。判断下一步该说什么，不需要这些信息；一旦泄露，代价却不可逆。地点记到「公司附近那家咖啡店」这种粒度就够。

**清空数据**：删除 `data/` 整个目录即可。也可以只删一条（`profile_tool.py forget --ids r3`），或导出后清空（`export` 生成可读的 Markdown 备份）。Skill 会退回安全默认值继续工作，不需要重装。

**共享设备**：风格卡和档案里有你的真实语句、你对别人的观察。如果这台机器不是私人的，把 `LOVE_REPLY_HOME` 指到加密卷或私人目录。**多台机器同步时不要放进公开仓库或公司网盘。**

## 三、危机情境

命中以下任何一类，**停止生成话术**，只输出求助渠道：

- 跟踪、骚扰、纠缠
- 威胁、恐吓、勒索
- 自伤、自杀意念
- 家庭暴力、人身伤害
- 疑似诈骗（情感诈骗、杀猪盘）
- 未成年人相关的性内容

处理顺序：

1. **先确认安全**。问一句「你现在安全吗」，不要先分析关系。
2. **明确边界**。说明这不是话术能处理的问题，不要用「你可以试着这样回」软化。
3. **给具体渠道**。中国大陆：110（报警）、12338（妇联维权）、12355（青少年心理）、120（急救）。涉及心理危机建议当地精神卫生中心或三甲医院精神科。
4. **不做二次伤害**。不追问细节，不评价对方，不说「你早该看出来」。

`references/kb/knowledge/17-中国法律安全与危机转介.md` 有完整清单与证据保存指引。路由表把这一类标为**最高优先级**，会覆盖其他所有路由。

## 四、使用侧的诚实提醒

工具不能替代判断，以下是这类工具本身的结构性局限：

- **它只看到你贴的那几行。** 关系的历史、语气、共同经历，它都不知道。判断基于片段，片段可能不代表整体。
- **它会顺着你的叙述走。** 你粘贴时已经做过一次筛选，选的是你认为重要的部分。它看不到你没提的。
- **它的建议是按「一般情况」给的。** 具体的人总有例外，而你比它更了解那个人。
- **它的价值在省时间，不在替你决定。** 三条候选的意义是让你少花十分钟组织语言，不是让你不用想。

如果发现自己开始依赖它决定每一句话，那已经超出工具该承担的范围了。
