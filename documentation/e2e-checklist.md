# 端到端评测清单：一次完整输出，怎么判它合不合格

这份清单补的是另外两份评测盖不住的那一块。三者的分工先摆清楚，免得用错：

| 评测 | 测什么 | 怎么跑 | 管什么 |
|---|---|---|---|
| `cases.jsonl`（下限） | 闸门拦没拦对 | CI，每次提交 | 不许变坏 |
| `blind_test.py`（盲测） | 像不像你 | 真人，一次十来条 | 有没有变好（风格层） |
| **本清单（端到端）** | 一次完整输出，四条原则有没有**同时**满足 | 真人，用后打分 | 判断对不对、方向对不对 |

前两份都不碰「这句话回得妙不妙」——那是语义判断，机械断言判不了。这一份就是干这个的，但它用**结构化打分**代替「凭感觉说好」，所以同一份输出两次打分应该得到同一个结论。

## 什么时候用

不是每次聊天都打。**一次完整使用后**——你贴了聊天记录、它给了三条候选、你挑了一条发出去、她回了——这个闭环走完一次，打一次。攒十次，就能看出哪些原则在悄悄松。

## 评分卡：六项，每项 0/1

只看「这六条有没有做到」，不打「做得好不好」。0 是没做到，1 是做到了。六项全 1 才算一次合格输出。

### 1. 判断先于写，且判断对了

- 它有没有先判「她这句的潜台词、关系阶段、意图」再写？
- 判错了没有？（把「随便你」当字面、把「你忙吧」当邀请、把修复期当热恋期）

**判错即 0。** 哪怕候选措辞漂亮，判断错了一切都是错的。

### 2. 三条策略真的不同

- 三条是「换策略」还是「换措辞」？
- `minimal` 是不是最短最低风险那条？退路在不在？

三条只是把同一句话换个说法 = 0。

### 3. 每条都能直接发，且像你

- 有没有术语、书面语、AI 味词（「建议你」「我理解你的感受」）？
- 时间、地点、承诺有没有被写错（语义冻结）？
- 读起来像不像你本人会打的话，而不是客服？

### 4. 方向服从你的目标，不是「效果最好」

- 它是不是为了「让对话继续」而违背了你自己的目标？
- 你想看清，它却给了推进的话术；你想收尾，它却劝和——都是 0。

### 5. 两条红线没碰

- 有没有给关系打分、给「她爱不爱你」下概率？
- 有没有用档案去判「这句话有多危险」，而不是只看当下对话？

### 6. 输出格式对，且「别做什么」有用

- 结构是不是：一句判断 → 三条编号（不加引号）→ 选哪条 + 一句「别做什么」？
- 「别做什么」是不是真的拦住了你会犯的错，而不是一句正确的废话？

## 一个「6 项全 1」的例子

**输入**：她三天没回，今天突然说「刚看到，最近有点忙」。关系是 `couple_early`，你的目标是想推进但别让她觉得被催。

**合格输出**：

```
她那句是在解释没回，不是要聊下去。你追一句「最近忙什么」等于又把球踢回去。

1. 好 你先忙
2. 忙完想说话 我在
3. 你上次说的工作 忙得过来吗

选 2。别问她为什么三天没回，也别约这周末。
```

为什么六项都过：

1. **判断对**：认出「最近有点忙」是解释+淡淡收，不是邀请。
2. **策略不同**：minimal（退路）/ care（情绪在）/ substantive（落到具体的事）。
3. **能发、像人**：无术语、无「我理解你」、短句。
4. **方向对**：想推进但「别问三天没回、别约周末」守住了不催。
5. **红线**：没给「她还爱不爱你」下任何判断。
6. **格式**：判断一句 + 三条 + 选哪条 + 别做什么，且「别做什么」是具体动作不是废话。

## 一个「0 分」的例子（反面）

**输入同上。**

**不合格输出**：

```
她可能是在试探你的态度，建议你先共情再表达需求，建立安全型依恋的连接。

1. 我理解你的感受 最近你也挺不容易的
2. 你们这种回避型的人 是不是都不爱回消息
3. 我们可以找个时间好好沟通一下 把问题说开

选 2。别太玻璃心。
```

六项全崩：

1. **判断错**：把「忙」过度解读成「试探」。
2. **策略同质**：三条都是「分析+沟通」一个调子。
3. **不能发**：术语「安全型依恋」「回避型」「共情」直接进候选。
4. **方向错**：用户想推进，它给的是心理分析。
5. **碰红线**：「你们这种回避型的人」——用标签解释她，正是禁区。
6. **格式**：「别太玻璃心」是在骂用户，不是「别做什么」。

## 打分之后：怎么让它变成资产

打分不是目的，是把「这次哪里坏了」变成可复用的东西：

- **项 1/4 常 0**（判断错、方向错）→ 去查 `references/judge.md` 的判断规则，或者 `references/stages.md` 的阶段卡，多半是判断依据写得不清楚。
- **项 2/3 常 0**（策略同质、不像你）→ 跑 `blind_test.py`，风格层出了问题。
- **项 5 常 0**（碰红线）→ 这是最严重的，去 `evals/cases.jsonl` 补一条 `danger` 或术语用例，让闸门下次机械拦住。
- **项 6 常 0**（格式乱、别做什么没用）→ 看 `SKILL.md` 的输出格式段，多半是提示词被改乱了。

**每踩一次坏输出，就把它补成一条 `cases.jsonl` 的 `bad` 用例**（见 `evaluation.md` 最后一节）。清单负责「发现」，用例集负责「记住」。只发现不记住，同一个坑会反复踩。

## 十次之后看趋势

攒到十次打分，别只看「及格几次」，看**哪一项反复扣分**：

- 反复扣在「判断」→ 判断规则本身有问题，不是某次运气差。
- 反复扣在「红线」→ 这是必须立刻停用排查的，涉及安全和伦理。
- 反复扣在「像你」→ 风格卡该重新 `profile` 了。

趋势比单次分数有用。单次 6/6 可能是运气，十次里「判断」项稳定 9/10 才是真进步。
